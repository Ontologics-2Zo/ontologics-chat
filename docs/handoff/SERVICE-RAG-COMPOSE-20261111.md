- **P3 답변 꾸러미·작성·검증** (`service/answer_compose.py`):
  - 꾸러미(전송 범위 A): 사실 ID·이름·출처·질적 상태(부족 있음/없음/미확인/서버 값), 근거 ID·종류·출처·검토 상태, 서버 판정, 식별자 목록. 계약 단계에서 식별자 밖 숫자를 거부한다(`PACKET_QUANTITY_FORBIDDEN`). BOM 원문·검색 본문은 넣지 않는다.
  - 모델은 숫자 자리에 `⟦F#⟧`만 쓴다. 서버가 검증 후 자기 계산값으로 바꿔 넣는다.
