## 무엇을 보여 주나

README 개요의 "질문 하나가 따라가는 지식 그래프" 도식과 같은 방식을 앱 탭(`#radial`, "홉 거리")으로 만들었다.

- 서버 스냅숏 그래프(`snapshot.graph.data`)의 객체·관계를 모두 쓴다. 객체·관계·방향·근거를 더하거나 합치거나 빼지 않는다.
- 중심(기본: 납품 회차)에서 기록된 관계를 양방향으로 따라간 최단 단계 수(hop)로 고리를 정한다. 중심과 연결이 없는 객체는 바깥 점선 고리에 둔다.
- 같은 고리 안에서는 한 단계 안쪽의 연결된 객체 각도 평균 순으로 정렬해 고르게 배치한다. 고리 반지름은 객체 수에 따라 늘어나 겹치지 않는다. 좌표는 표현일 뿐이다.
- 고리마다 개수와 가장 많은 종류를 표시한다. 8874 원장 v23: 50·53·18·87·84·11·8·4, 연결 없음 11 (README 도식과 같음).

## 질문과 근거

- 탭 옆에 질문 패널이 있다. 같은 읽기 질의 API를 쓰고, 답의 `evidence_node_ids`·`evidence_edge_ids`만 강조한다. 근거는 중심에서 바깥 고리 순으로 드러난다. 강조 밖 객체는 층 하나의 opacity로 흐린다(DEC-H72).
- "수율을 적용하면…" 질문의 근거 노드는 177개다(README 도식과 같음).
- 이름표: 중심·선택 객체, 핵심 종류, 같은 종류가 3개 이하인 근거에만 붙인다. BOM 행·원문 행 관계는 가는 선으로 그린다.
- 다른 버전의 답변 근거는 기존과 같이 같은 스냅숏일 때만 재생한다.
