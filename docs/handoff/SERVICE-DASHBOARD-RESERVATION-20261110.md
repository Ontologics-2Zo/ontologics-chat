### 레퍼런스 단일 시트·5품목 연결·시연 시작점 (후속, DEC-H48 범위)

- BOM 등록은 추출 후 한 페이지 시트로 표시한다: 등록 초안/검토·승인(초안 → 승인 요청 → 승인 → 반영) → 개정 식별 → 추출·검증 → 개정 대비 차이 → 사내 품목 연결. 단계 칩은 해당 블록으로 이동만 한다. 문서 선택·검토 의견·원본 관리는 접힌 상세에 둔다.
- 새 초안에는 INITIAL 기초 원장의 `mapping_candidates`(시연 매핑 가정 5행, `applied=false`)를 원문 행 번호·위치가 정확히 같은 미확인 행에만 초안으로 채운다(`candidateDecisions`). 과거 승인·판단을 복사하지 않으며 작성자가 `등록 초안 저장 · 승인 요청`으로 저장해야 기록된다. 검토자의 `승인`은 검토 기록과 정확 버전 승인을 서버 명령 2개로 남기고, 반영은 별도다.
