# 공개 저장소와 비공개 입력의 경계

2026-11-08 사용자 결정은 **공개 저장소 유지, 원본 자료 별도 보관**이다. 이 정책은 업로드할 자료의 범위를 정하며, 이번 인계 작성은 업로드를 실행하지 않는다.

| 구분 | 저장 위치 | 공개 조건 |
|---|---|---|
| 새로 작성한 개발 지침·작업표·요구 ID 추적 | 공개 저장소 후보 `repo/` | 실제 원문·개인 경로·비밀·상세 평가 응답이 없는지 검토 |
| 공식 문서 3개·과거 검토 문서 | Git 밖 비공개 입력 | 원문 자체를 공개용 ZIP에 넣지 않음 |
| MK-S2 원본 HTML·schema·fixtures | Git 밖 비공개 입력 | 공개 프론트로 옮길 부분은 재사용·재배포 조건과 내장 원본 데이터 제거를 확인 |
| 실제 BOM·정규화 결과·원본 파생 v1.3 그래프 | Git 밖 비공개 입력 | 합성 운영 사건이 섞여 있다는 이유만으로 전체 공개 fixture로 분류하지 않음 |
| 모델 정답·응답·trace·상세 실험 결과 | Git 밖 PRIVATE_EVAL_ROOT | 공개 보고는 비식별 집계와 한계만 |
| 코드·공통 테스트·독립 합성 fixture | 향후 공개 저장소 | 원본 값·텍스트 복제가 없는지 확인 후 추가 |
| 운영 감사 기록 | 보호된 서비스 저장소 | 개인 평가 저장소로 옮기거나 삭제하지 않음 |

공개용 ZIP과 비공개 원본 폴더를 별도로 제공한다. 인계 폴더 전체를 Git에 넣지 않는다. `.gitignore`·`.dockerignore`는 추가 방어이며, 원본의 기본 위치는 저장소 밖이다.

공개 배치 전 파일 목록을 allowlist와 비교하고, 추적 파일·압축 파일·큰 파일·키·개인 경로·내장 fixtures·이미지/로그를 확인한다. 이 인계본의 공개용 후보는 문서·메타데이터와 제외 설정만 포함한다. 아직 서비스 코드나 MK-S2 HTML을 공개 배치하지 않았다.

원본을 참고해 구현한 화면 코드까지 무조건 비공개라는 뜻은 아니다. 원본 파일을 공개하지 않으면서 구현물을 공개할 수 있는 범위를 재사용 조건에 맞춰 확정한다. 조건이 확인될 때까지 원본 HTML을 통째로 복사하는 방식은 사용하지 않는다.
