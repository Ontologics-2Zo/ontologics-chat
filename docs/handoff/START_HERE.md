# MK-S2 개발 인계 안내

대상 저장소는 `Ontologics-2Zo/ontologics-chat`이다. 화면·메뉴·핵심 동선은 MK-S2를 기준으로 삼고, 공식 v1.7의 전체 아키텍처와 업무 범위를 유지한다. 현재 인계는 새 서비스 코드가 없는 상태에서 사용할 계획·검증 계약이다.

## 자료를 읽는 순서

1. [아키텍처 기준](ARCHITECTURE_BASELINE.md): 유지할 구조와 최신 사용자 결정.
2. [구현 작업표](IMPLEMENTATION_TASKS.md)와 [기계 판독 작업표](TASKS.json): 공식 T00~T23의 의존성과 단계별 완료 조건.
3. [화면별 대응](SCREEN_ACCEPTANCE_MAP.md)와 [인수 게이트](ACCEPTANCE_GATES.md): 화면에 보일 결과와 검증 증거.
4. [데이터 반입 계약](DATA_IMPORT_CONTRACT.md): v1.3 초기화와 합성 원장, 실제 BOM 검수 구분.
5. [자료 인덱스](SOURCE_INDEX.md): Git 밖 공식 원문과 hash 확인.
6. [비공개 원본 전달 방법](PRIVATE_INPUT_DELIVERY.md)과 [준비 전용 요청문](PREPARATION_ONLY_REQUEST.md). 서비스 개발은 별도 요청 전까지 시작하지 않는다.
7. [결정·미결 사항](DECISIONS_AND_BLOCKERS.md), [Cloud 준비](CLOUD_SETUP.md), [첫 실행 요청문](FIRST_CLOUD_TASK.md).

## 적용 기준

- 사용자의 최신 명시적 결정 → 공식 v1.7의 기능·도메인·아키텍처 → MK-S2의 화면·동선과 참고 규약 → 인계 작업표 순서로 읽는다. 최신 결정은 화면 기준과 구현 우선순위를 조정하며 공식 업무 요구를 폐기하지 않는다.
- 공식 문서에 남아 있는 과거 v2.6 UI 배치·메뉴 고정 지시는 MK-S2 우선 결정으로 대체됐다. 공식 화면 ID의 업무 의미·수용 기준은 보존하고 화면 대응표로 재배치한다.
- 이전 GitHub 구현은 재사용 후보 조사 자료다. 코드가 있거나 과거 테스트가 통과했다는 사실만으로 새 서비스에서 완료 처리하지 않는다.
- 과거 계획 문서에 적힌 ‘이번에는 코드 변경하지 않음’은 당시 분석 작업의 상태다. 이후 별도로 받은 개발 요청의 범위를 막는 영구 금지로 해석하지 않는다. 이 인계본 작성 자체는 코드 개발 착수 승인이 아니다.

## 단계별 완료 명칭

| 단계 | 완료로 부를 수 있는 것 | 별도 남겨야 하는 것 |
|---|---|---|
| 인계 준비 | 문서·의존성·자료 분리·검증 계약 | 서비스 코드와 Cloud 실행 |
| 공통 기반 | 실제 API/DB·신원·승인·SDK·관측·복구·파일 처리 경계 | 업무별 완성, 실제 AI 품질 |
| 1차 MK-S2 | 질문→BOM→소요/견적→구매→입하/수입검사→가용 재고의 서버 처리 | 전체 68대 고객 도착·전체 v1.7 인수 |
| 후속 업무 | 같은 LOT의 3→2→1 및 전체 고객 도착, 범용 추적·클레임 등 | 실운영 연계·규모·사용자 효과의 별도 인수 |

1차에도 생산·출하·도착 현황 조회를 유지한다. 자재 확보만 완료된 상태에서 남은 도착 약속 68을 0으로 바꾸지 않는다. 전체 목표는 실제로 100대 도착·잔여 0을 기록하는 후속 시연까지 보존한다.

## 공개 저장소와 비공개 원본

2026-11-08 사용자는 공개 저장소 유지·원본 별도 보관을 결정했다. Git에는 새 작성 문서·공통 코드·승인된 공개 fixture만 넣는다. 원본은 `PRIVATE_INPUT_ROOT`로 별도 제공한다. 개인 컴퓨터의 첨부 경로는 Cloud에서 자동으로 사용할 수 없다.

최초 인계 준비에서는 원본을 복사·hash 확인했으며 원본 파일을 수정하지 않았다. 후속 사용자 요청은 공개 문서의 GitHub 배치를 허용했다. Cloud 환경 변경·비공개 원본 전송·서비스 구현·유료 모델 호출·공급사 송신은 이번 범위에 포함하지 않는다.

## 다음 실행

공개용 인계 파일을 검토해 저장소에 반영하고, 비공개 원본 접근과 Cloud 실행 환경을 준비한 뒤 첫 요청문을 사용한다. 첫 요청은 T00~T01에 한정한다. 원본이 없는 경우 T00 미완료를 기록하며, 가능하면 공개 문서만으로 할 수 있는 환경 조사·골격 준비를 분리해서 진행한다.
