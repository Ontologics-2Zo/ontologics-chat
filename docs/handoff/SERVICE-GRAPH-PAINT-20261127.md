## 증상

프로젝트 그래프(`#network`)에서 질문하면 근거 경로를 단계별로 확대하며 선을 그린다. 이때 화면이 끊겼고, 창을 전체화면으로 키우면 깜빡였다.

## 원인 (8874, 원장 v23, 객체 327·관계 696, 브라우저 측정)

| 원인 | 영향 |
|---|---|
| 흐리게 할 객체마다 `opacity`를 따로 걸었다(약 1,000개) | 카메라 이동·선 그리기 중 매 프레임 1,000개 합성 그룹을 다시 칠했다. 프레임 50~85ms |
| 재생 단계마다 SVG 요소 약 5,800개를 지우고 다시 만들었다 | 단계가 바뀔 때마다 30~70ms 정지 |
| 숨긴 관계 이름표 696개를 `opacity: 0`으로 숨겼다 | 보이지 않는 글자도 매 프레임 칠했다. 큰 화면에서 두드러졌다 |
| BOM 원문 행 관계마다 그룹 `opacity`를 걸었다 | 약 400개가 각자 합성 그룹이 됐다 |

## 수정

- 그래프 요소는 마운트 때 한 번만 만든다. 재생 단계·선택·종류 강조는 클래스만 바꾸고, 흐릴 객체는 `mks-dim-layer` 층으로 옮긴다. 층을 오갈 때 원래 그리는 순서를 유지한다.
- 흐림은 층 하나의 `opacity`로 적용한다.
- 숨긴 이름표는 `visibility: hidden`으로 숨긴다. 마우스 올림·포커스·근거 강조 때 보이는 동작은 같다.
- BOM 행 관계는 경로의 `stroke-opacity`로 옅게 한다(.22, 강조 .5, 재생 중 .72, 마우스 올림 1).
- 노드·관계 수, 좌표, 재생 순서, 취소·reduced-motion 동작은 바꾸지 않았다.
