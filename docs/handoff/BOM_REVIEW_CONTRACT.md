# MK-S2 BOM 검토 화면·비교 규약

DEC-H33의 구현 기준이다. 공유 MK-S2의 등록·통합 검토·품목 연결 동선을 서비스에 적용하며, 원본 HTML의 고정 결과나 메모리 승인을 실제 원장으로 사용하지 않는다.

## 단계 표시

- 현재 보고 있는 단계는 보라색 테두리, 서버 기록으로 완료된 단계는 초록색, 미해결 확인이 있는 단계는 주황색으로 구분한다. 탭 방문만으로 완료시키지 않는다.
- 접수 대기 중 진행 바는 실제 요청 수명에 맞춘다. 임의 퍼센트나 자동 완료 시간을 만들지 않는다.
- 원문 등록 승인과 제조 기술검수는 별개다. 등록·승인·반영이 끝나도 원본 식별 충돌과 미연결 행은 확인 필요로 남는다.

## 개정 비교

- 사용자가 비교할 저장 문서를 선택한다. 서버는 같은 회사와 조회 권한, 양쪽 문서의 정확 버전/hash를 확인한다. 파일명이나 최신 날짜만으로 개정 계보를 정하지 않는다.
- 위치 표기와 원문 수량·셀 값을 결정적으로 비교한다. 기준 문서가 없으면 비교 기준 없음, 동일 원본이면 원문 변경 없음으로 표시한다. 원본의 경고와 문서별 검수·승인은 별개다.
- 단일 시트끼리는 시트명이 달라도 경고와 함께 위치를 비교한다. 다중 시트의 불일치, 중복 위치, 행 분할·병합, 미확인 위치·수량은 대응 확인 필요로 남긴다. 행을 합산하거나 임의로 대응시키지 않는다.
- 추가·삭제·변경·동일은 대응 가능한 행의 수다. 대응 확인은 양쪽의 미해결 원문 행 수이므로 변경 건수와 단위가 다르다. 변경 원인은 수량과 원문 값이 겹칠 수 있다.
- 비교는 읽기 전용이다. 이전 품목 연결·검토·승인을 복사하지 않고 신규 문서, 원장, 투영, 모델 호출을 만들지 않는다. 제조 구성의 동일성은 UNKNOWN이다.

## 품목 검토

- 기본 화면은 연결 결과 표다. 필요한 행을 선택하면 적용 상태·사내 품목·대당 수량·단위를 고르는 패널만 펼친다. 원문·이전 의견·추가 의견과 직접 입력은 상세에 둔다.
- 후보가 하나여도 자동으로 선택하지 않는다. 사내 품목은 현재 원장 목록에서 고르고, 같은 코드가 여러 개면 확정하지 않는다. 단위 후보는 현재 기록에서 온 제안이며 공식 단위 기준정보로 승격하지 않는다.
- 원문 수량을 대당 수량으로 사용할 때도 명시적으로 선택해야 한다. 선택값은 현재 승인된 조건부 시연 범위의 DEMO_ASSUMPTION이다. 원문 대조·제조 검수 완료를 자동 생성하지 않는다.
- 미확인·비실장·설정 행의 품목·대당 수량·단위는 null로 유지한다. 미확인을 수량 0이나 부족 0으로 바꾸지 않는다.
- 선택 내역과 원문 위치를 근거 문장으로 자동 기록한다. 추가 의견은 선택 사항이다. 이는 사용자의 선택 기록이며 전문가 검수 증거를 대신하지 않는다.
- ‘초안에 담기’는 브라우저 임시 판단이다. 서버 초안 저장, 독립 검토, 정확 버전 승인, 원장 반영은 기존의 별도 명시 동작으로 유지한다.

## 실제 제조 적용 전에 필요한 업무 기준

제품 구성과 유효 리비전, 행별 사내 품목/MPN 동일성, 실장·제외 기준, 원문 수량의 의미와 단위 환산, 대체품 승인 기준이 필요하다. 재고·예약·보류와 생산·수율 기준도 별도 근거로 확정해야 한다. 화면을 선택형으로 바꾼 것은 이 기준을 승인한 것이 아니다. 그 전까지 원문 전체와 미확인 상태, 시연 가정을 구분한다.
