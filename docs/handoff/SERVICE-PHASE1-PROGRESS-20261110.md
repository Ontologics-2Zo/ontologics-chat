## 화면 동작

- 핵심 관계를 단계당1.45초, 카메라 이동650ms로 표시한다. BOM 관계는2.4초 동안 같은 진행값으로 함께 그린다. 기존 바탕선·노드·ID는 계속 보존한다. 한 화면의 개별 관계는 최대14단계이며 나머지도 삭제하지 않고 한 묶음으로 보여준다. 정상 CQ의 실제 재생 시간과 브라우저 검증은 아래에 별도로 기록한다.
- `거친 노드165개`는 핵심6개와 `전체 근거165개 보기`로 표시한다. 정확한 snapshot의 서버 객체 타입을 사용하고, 나머지159개는 접힌 목록에 보존한다. 펼친 목록은 높이를 제한해 채팅 전체를 밀어내지 않으며 모든 노드의 클릭 이동을 유지한다.
- 조회 단계는600ms 간격으로 대기→표시 중→완료가 되고 이어서 본문을 표시한다. 서버 요청이 이미 끝난 뒤의 표시 효과이며 실제 처리 시간/진행률로 사용하지 않는다. 모두 보기·동작 줄이기는 즉시 표시하고, 새 질문/탭/refresh/계정 변경에서 기존 수명주기와 기준 버전을 유지한다.
- 기존 디지털 트윈 배치·보호 화면7파일과 수량/출처/UNKNOWN은 보존한다. 적용 정보가 없는 현재 BOM을 부족0이나 제조 가능으로 바꾸지 않는다.

## LangSmith 확인과 전송 경계

연결이 보이지 않던 원인은 키가 없어서는 아니었다. 기존 코드에는 키 로드만 있었고 자동 LangGraph tracing은 의도적으로 OFF, LangSmith exporter는 미구현이었다. 기존 키로 공식 API의 프로젝트 목록을 읽어 인증HTTP200을 확인했다. 기존 환경별 프로젝트 중 Mac에 해당하는 `local` 프로젝트를 사용하며 새 프로젝트/플랜 변경은 하지 않는다.

DEC-H19의 기존 승인은 합성·비식별 메타데이터다. DEC-H43의 질문/최종답변 상세 승인은 **로컬 Langfuse에 한정**된다. 따라서 LangSmith에는 실행/시도 ID·단계·상태·시간·허용 버전·확인된 사용량만 보내고 입력/출력 본문은 비운다. BOM 원문·고객/회사 내용·개인 평가 질문/정답·키·환경 전체·비공개 경로는 보내지 않는다. SDK 자동 tracing을 켜는 방식으로 우회하지 않는다.

격리 서비스·브라우저와 실제 관측 수신 검증을 통과했다. Mac 원래 서비스의 활성화·보존 대사는 이어서 기록한다. 전체 1차 인수의 완료를 뜻하지 않는다.

- 서비스: `.venv/bin/python -m unittest discover -s tests -q` 426 PASS/실패 0/skip 0. 별도 PostgreSQL·Neo4j와 기존 제한 Runner에서 실행했다. 외부 통신과 원래 서비스 포트를 막고 제공자 키 없이 Fake로 검사했다. 실행 중 코드 hash 전후 동일. Runner 16개 강제 통제의 증거는 같은 코드·이미지의 직전 검증을 재사용했으며 새 강제 검사로 세지 않는다.
- UI 모듈: `node --test tests/test_*.mjs` 161 PASS/실패0/skip0. 실제 glob 확장 argv 사용. 그래프16·query32·host25 포함. `git diff --check` PASS.

- 현재 canonical 예산 사전 기준: live35회, 확정US$0.01428, 기존 미확정예약US$0.016414, 잔여US$9.969306. 이전 turn의34회 값으로 되돌리지 않는다.
- 원본155·제공 참조11·보호 화면7·기존 사용자 파일9·runtime/.env를 보존 대상으로 기록했다. 상세 원문·로그·스크린샷·trace·인증 파일은 Git 밖에 둔다.

LangSmith의 실제 기존 local 프로젝트에 격리 합성 Fake 실행 1회를 전송해 6개 run을 다시 조회했다. 로컬 Langfuse의 6개 observation과 execution/attempt/부모 관계가 일치했고, LangSmith의 입력·출력은 비어 있으며 합성 질문·답변은 로컬 Langfuse에만 있다. 같은 실행의 재요청은 추가 Fake 호출과 업무 변경을 만들지 않았다. 실모델 호출은 0회다. API가 빈 객체를 `null`로 반환하는 차이는 읽기 검증기에 반영했으며 추가 POST 없이 같은 run을 확인했다.

전송은 별도 목적지 영속 큐와 단일 비동기 worker를 사용한다. 불명확한 전송을 자동 재시도하지 않으며 재시작 후 중복 전송하지 않는다. SDK 자동 tracing은 계속 OFF다. 본문 기록이 없는 metadata chain으로 보내므로 LangSmith의 자동 모델 비용 추정과 canonical 원장 비용을 합산하지 않는다. WAITING 실행은 terminal root가 생긴 뒤 연결되며, 이전 trace를 소급 전송하지 않는다.
