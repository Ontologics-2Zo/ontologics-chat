# 답변 표시와 적용 BOM 선행 조건

2026-11-10 · DEC-H45 · 기반 `9edfa20` · `codex/service-progress-evidence` / [Draft PR #6](https://github.com/Ontologics-2Zo/ontologics-chat/pull/6) 후속.

사용자는 본문을 순차 표시한 뒤 근거·출처·버전·버튼을 함께 표시하고, 채팅의 ‘근거 다시 보기’를 ‘그래프에서 보기’로 바꾸도록 요청했다. 납품 회차→제품 구성→적용 BOM→품목→가용 재고·조달→생산·검사·운송의 흐름에서 현재 적용 BOM 근거 부족을 먼저 안내해야 한다는 요구도 반영한다. 기존 파일·DB·모든 노드/관계·같은 모델 예산을 유지한다. 이번 변경으로 원문 등록 승인이나 과거 시연 판단을 현재 제조 적용 승인으로 승격하지 않는다.

## 진단과 구현 범위

- 화면에는 접근성용 전체 본문과 타이핑 본문을 별도로 만들고 있었다. 숨긴 복사본도 텍스트 복사/추출에 중복될 수 있어 본문 DOM을 하나로 유지한다. 순차 표시 완료 시 보조 정보 묶음을 한 번에 공개하며, 모두 보기·동작 줄이기·화면 전환·취소 경계를 유지한다. 실제 provider streaming이 아닌 서버 확정 답변의 표시 효과다.
- 서버는 원문 등록 여부와 계산 가능한 적용 판단 여부를 충분히 구분하지 않아 ‘0개 품목 조회’라는 문구를 냈다. 기존 수량/부족 계산을 유지하면서 읽기 전용 선행 조건 DTO와 현재 문서의 정확 ID/version/hash를 반환한다. 미등록·적용 검토 0·부분 검토·검토 결과 적용 대상 0·제조 기술검수 미확인을 구분한다. 선택 품목의 미연결을 전체 BOM 부재로 취급하지 않는다.
- 현재 반영본은 원장 v4의 문서 v3이며, 원문 74행 모두 적용 미확인이다. 역사 v2의 선택 5품목 조건부 판단과 원문은 보존되어 있다. 후속 원본 등록 문서가 활성 BOM이 됐으며 이전 판단을 자동 이월하지 않았다. 이는 파일/DB 삭제나 초기화가 아니다.
- 현재 상태의 납기 답변은 ‘원본 등록 완료·적용 검토 필요’를 먼저 말하고 다음 행동을 안내한다. 합성 기초 원장의 68대/40대는 출처와 함께 구분한다. 요청하지 않은 94%/43대 가정은 상세 근거에 보존하며 명시적인 수율·투입 질문에서는 본문에도 표시한다. 계산 가능한 기존 품목의 정확한 소요·부족 설명을 없애지 않는다.
- `BOM 적용 검토`는 같은 snapshot과 현재 문서의 정확 ID/version/hash/구성을 확인한 뒤 기존 품목 연결 화면을 읽기 전용으로 연다. POSTED 문서는 수정하지 않는다. 작성 중인 초안 선택 또는 보관 원본으로 새 초안 접수, 검토·독립 승인·반영은 각각 사용자가 명시 실행한다. 버튼을 눌러도 원장·판단·승인을 복사하거나 새 문서를 자동 생성하지 않는다.

연결 요구는 SD-002~005/SD-029, UX-H01~03, HG-04, T09.1/T12.1/T19.1/T22.1이다. 전체 1차/HG-04 인수·제조 기술검수·납기 확정·main 병합은 별도다.

## 공유 MK-S2 구성과 움직임 대조

후속 요청에 따라 제공된 MK-S2 원본의 그래프 질의와 업무 에이전트 구현을 각각 확인했다. 원본 그래프 질의는 점검 줄→근거 재생→문단·칩·버전, 업무 에이전트는 번호 카드의 순차 등장과 BOM 미충족 단계 중단이다. 원본 내장 수치·고정 답변·미래 사건은 가져오지 않았다.

- 업무 에이전트: 서버의 같은 조회 결과를 `answer_blocks`로 제공한다. 현재 납기 질문은 확인된 수량→제품 구성·등록/적용 상태→BOM 검토 행동의 3개 카드이며, 각 카드의 글자를 표시한 뒤 다음 카드로 진행한다. 번호·제목·우측 조회 표시·경고 카드와 여백을 원본 기준으로 맞춘다. 카드 수를 실제 도구/모델 호출 횟수로 표시하지 않는다.
- 그래프 질의: 확인 줄 표시 뒤 기존 근거 재생을 기다리고 본문을 표시한다. 모든 정보가 확정된 뒤의 표현이며 실제 서버 진행률이나 LLM 내부 추론 표시가 아니다. ‘모두 보기’로 기다림을 건너뛰고, 늦은 완료가 새 답변/종료된 화면을 되살리지 않게 한다.
- 두 화면 모두 본문 완료 후 보조 정보 묶음을 한 번에 보여 준다. 사용자가 과거 대화로 스크롤하면 자동 하단 이동을 멈춘다. 동작 줄이기 설정에서는 즉시 표시한다. 기존 느린 핵심 관계·BOM 일괄 재생과 모든 근거 ID는 유지한다.
