# BOM 검토 화면 통합 · 2026-11-09

DEC-H32에 따른 MK-S2 표현 계층 변경이다. 기존 서버 보관 파일 선택을 유지하고, 접수 후 실제 서버 응답 대기 → 추출·검증 결과 → 품목 연결을 공유 MK-S2 원본의 동선에 맞췄다. 부모 T09/T12와 전체 1차 서비스 완료는 아니다.

## 구현과 경계

- `web/mks2/bom.js`: 접수 요청이 진행 중일 때만 무한 진행 바를 표시한다. 퍼센트·타이머로 완료를 만들지 않는다. 실패하면 원본 선택과 동일 요청 키를 보존하며, 성공해야 품목 연결 단계로 이동한다.
- 개정 식별·추출/검증·개정 차이·품목 연결을 한 페이지에 배치했다. 8단계는 유지하고 앞의 검토 섹션 간 이동은 스크롤로 처리한다. 연결 행을 먼저 표시하는 표와 기존 행별 검수 폼을 연결했다. 전체 원문 표는 원문 순서를 유지한다.
- 입력 중인 폼은 섹션 이동·원본 다운로드 중 유지한다. 임시 입력은 명시적으로 담은 검수 판단과 별도이며, 저장/검토/승인/반영 요청에 자동 적용하지 않는다. 다른 문서 조회·서버 저장 결과는 임시 입력을 초기화한다.
- 경고는 해당 문서의 파일명·행 근거를 표시한다. 수량 미확인과 위치 식별값 누락을 나눠 집계하고, 반복 표기를 곧바로 실제 중복 실장으로 설명하지 않는다. 기존 서버 경고 코드·원본·검수 판단은 변경하지 않았다.
- `web/mks2/dashboard.css`: 진행 바, 한 페이지 배치, 표 내부 스크롤과 동작 축소 설정을 지원한다.
- 자동 개정 전후 비교는 여전히 미연결로 표시한다. 원본 목업의 고정 비교 결과·메모리 승인을 복사하지 않았다. 파일 업로드 API·파서·DB 스키마·업무 명령은 변경하지 않았다.
